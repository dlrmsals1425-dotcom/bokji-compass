# 복지나침반 Sites 배포

- 원본: `dlrmsals1425-dotcom/bokji`, `jinwoo-ui`, 커밋 `81eae659e7a6a1fae0d90371d34b307611ab8ee8`.
- 배포 원본은 이 폴더이며 기존 GitHub 체크아웃과 별도로 관리한다.
- Sites ID는 `.openai/hosting.json`에 보존한다. 같은 사이트를 다시 생성하지 않는다.
- 원본 `src`와 `public`의 UI·전국 데이터·GPS·음성 경로를 이관했다.
- 실행 환경은 Sites Vinext/Cloudflare Worker다. 음성 API는 서버의 `OPENAI_API_KEY` 비밀 설정을 사용한다. 키는 소스·브라우저 번들·아카이브에 포함하지 않는다.
- 상세 페이지의 서버 메타데이터는 `ASSETS` 바인딩으로 공개 데이터 번들을 읽는다. 사용자 입력과 좌표는 기존처럼 브라우저에서 처리한다.
- Vinext 기본 Link의 prefetch/navigation 오류를 재현해 `SiteLink`에서 `useRouter`로 내부 이동을 처리한다. 새 탭·수정키·외부 링크의 기본 동작과 GPS 조회 공유를 보존한다.
- Sites 기본 비공개 접근을 유지한다. 공유 범위를 변경하려면 별도 사용자 요청이 필요하다.
- 원본 데이터의 기준일·출처·불확실성 표시는 유지하며, 호스팅 이전은 데이터 내용의 최신성 재검증을 뜻하지 않는다.

소스 동기화·빌드·게시에는 Sites 스킬의 `site-workflow.mjs`, `build-site.mjs`와 네이티브 배포 도구를 사용한다. API 키가 없는 로컬 미리보기의 음성 상태 503은 정상이며, 게시 후 서버 설정과 실제 전사 성공을 구별해 확인한다.

2026-10-20 이관 검사: TypeScript 검사·Sites 빌드 통과. 최초 브라우저 검사 6개 중 홈 링크 오류 2개를 수정한 뒤 데스크톱/모바일 12개를 작업자 1개로 통과했다. 홈 모션·GPS 재사용·질문에서 결과까지·가구/자녀 분기·모의 실시간 음성·마이크 거절 대체 입력을 확인했다. 상세 페이지의 실제 번들 메타데이터 HTTP 200도 확인했다. 이번 화면 검사는 합성 이벤트를 사용했으며 실제 사용자 마이크를 시험한 것은 아니다.

Windows의 로컬 도구는 번들 Node 24.19와 Git Bash를 사용했다. 패키징할 때 Windows 드라이브 문자를 tar 원격 경로로 해석하지 않도록 해당 실행에만 `TAR_OPTIONS=--force-local`을 설정한다.
